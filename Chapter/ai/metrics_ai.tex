\subsubsection{Confusion Matrix}
In the context of outlier detection, which is framed as an imbalanced binary classification problem, performance is evaluated using a $2\times2$ confusion matrix. 
This matrix facilitates a direct comparison between the predicted classifications and the actual ground truth labels. 
The structure of the confusion matrix is organized such that the horizontal axis represents the predicted classes generated by the detection method, while the vertical axis represents the true classes. 
Each observation is assigned to one of the four cells based on this comparison: True Positives ($TP$) and True Negatives ($TN$) represent correct identifications of anomalies and inliers, respectively, whereas False Positives ($FP$) and False Negatives ($FN$) represent misclassification errors. 
This systematic categorization serves as the empirical foundation for calculating more complex performance metrics that account for the specific requirements of anomaly detection.

The $F1-score$ represents the harmonic mean of precision and recall, providing a unified metric that accounts for the inherent tension between these two measures. 
Due to the mathematical properties of the harmonic mean, the score is significantly influenced by the lower of the two values.

Consequently, a high $F1-score$ is only achievable when both precision and recall are simultaneously high. 
As previously established, these two metrics exist in a trade-off relationship, where adjustments to the classification threshold that improve one typically result in the degradation of the other. 
By optimizing the $F1-score$, the model effectively seeks a balance that minimizes both false positives and false negatives, making it a robust evaluation tool for imbalanced outlier detection tasks. 
The $F1-score$ is formally defined as:

\begin{equation}
    F_1 = 2 \cdot \frac{\text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}}
\end{equation}

While Accuracy, Precision, Recall, and Specificity are derived from the fundamental components of the confusion matrix, these values are intrinsically dependent on the selected classification threshold. 
Accuracy remains a prevalent metric in the field, as discussed above.
However, Accuracy is fundamentally inadequate for outlier detection due to the inherent class imbalance of such datasets. 
Because the minority class of outliers is significantly smaller than the majority class of inliers, the mathematical influence of outliers on the total Accuracy score is disproportionately low. 
In scenarios with a minimal percentage of outliers, a model can achieve a high Accuracy score by simply classifying all instances as inliers, thereby masking a total failure to detect anomalies. 
Consequently, performance metrics for imbalanced datasets must account for the actual class distributions to ensure an objective evaluation \citep[p.8]{branco2016survey}.

Precision attempts to mitigate the issues inherent in Accuracy by excluding the distribution and count of true negatives; however, this approach introduces distinct limitations. 
By disregarding true negatives, a model can be optimized for Precision through overly conservative classification, wherein it identifies only the most unequivocal outliers.
Conversely, Recall is analytically trivial to maximize, as a model can achieve a perfect score of 1.0 by designating every data point as an outlier. 
A model that flags all instances is technically perfect regarding Recall but lacks practical utility due to its complete inability to discriminate between classes. 
Because the count of false positives is absent from the Recall equation, a high-recall model in contexts such as fraud detection may flag numerous legitimate transactions as fraudulent. 
The operational cost of investigating these false alarms is significant, yet Recall fails to reflect this noise. 
Consequently, it is difficult to determine the superiority of a method based solely on Recall without accounting for a concurrent increase in false positives. 
Furthermore, \citet{chicco2020} argue that because Recall ignores two quadrants of the confusion matrix, it provides an incomplete and potentially biased summary of model quality. 
This is particularly problematic for unsupervised outlier detection algorithms that generate continuous anomaly scores, as lowering the threshold can artificially inflate Recall, necessitating the use of threshold-independent metrics like ROC AUC or PR AUC for objective comparison.
